Pertanyaan Umum

Apakah aplikasi ini 100% gratis? +

Ya, 100% gratis. Tidak ada biaya apa pun. Tidak ada iklan. Semoga bermanfaat untuk masyarakat yang sedang berduka.

Apakah data saya aman? +

Sangat aman. Semua proses dilakukan langsung di browser perangkat Anda. Kami tidak menyimpan data almarhum maupun keluarga di server mana pun.

Bagaimana cara kirim PDF ke WhatsApp? +

Klik tombol "Download PDF / Cetak", file akan tersimpan di perangkat Anda. Buka WhatsApp, pilih kontak atau grup, klik ikon lampiran (📎), pilih "Dokumen", lalu kirimkan file PDF tersebut.

Mengapa preview terlihat kecil di HP? +

Di layar HP, preview diperkecil agar kertas A4 muat di layar. Saat di-download, PDF akan berukuran normal A4 standar yang rapi untuk dicetak.
